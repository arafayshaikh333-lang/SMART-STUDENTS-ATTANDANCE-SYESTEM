# Astra Gemini AI Assistant — Complete Source Code & Free Hosting Guide

Yeh folder aapki **Astra Gemini AI Assistant** website ka mukammal source code hai.

## 📁 Files Included
1. `index.html` — Website ka main structure aur modern UI layout.
2. `style.css` — Custom animations, scrollbars, aur Markdown styling.
3. `app.js` — Google Gemini 2.5 Flash API integration, Live Google Search Grounding, Voice Mic (Urdu/English), Read Aloud TTS, aur Image Vision logic.
4. `README.md` — Website ko 1 minute mein Free Public karne ka tarika.

---

## 🚀 Isko FREE Mein Public (Live) Kaise Karein?

### Tarika 1: Netlify Drop (Sab Se Asaan — 30 Seconds Mein Live)
1. Sab se pehle is ZIP file ko apne computer ya mobile par **Extract (Unzip)** karein.
2. Browser mein [https://app.netlify.com/drop](https://app.netlify.com/drop) kholein (Free account bana lein).
3. Apna extracted folder (`astra-gemini-ai`) utha kar seedha Netlify Drop wale box mein **Drag & Drop** kar dein (ya Upload Folder select karein).
4. **10 seconds** ke andar aapko ek live public link mil jayega (jaise `https://astra-ai-assistant.netlify.app`), jise aap duniya mein kisi ke sath bhi share kar sakte hain!

### Tarika 2: GitHub Pages (Lifetime Free Hosting)
1. [GitHub.com](https://github.com) par ek free account banayein aur **New Repository** create karein.
2. Repository mein `index.html`, `style.css`, aur `app.js` upload kar ke **Commit** karein.
3. Repository ke **Settings > Pages** mein jayein, Branch mein `main` select karein aur **Save** dabayein.
4. 1 minute mein aapki website `https://yourusername.github.io/repo-name` par live ho jayegi!

## 🔑 Free Google Gemini API Key Kaise Lagayein?
1. [Google AI Studio (https://aistudio.google.com/app/apikey)](https://aistudio.google.com/app/apikey) par jayein.
2. **Create API Key** button par click karein aur key copy kar lein.
3. Apni website khol kar left sidebar mein **Gemini API Key Setup** par click karein aur key paste kar ke Save kar dein.
